# python-seguranca

Projetos práticos em Python voltados para segurança da informação. Aqui eu transformo o que estudo (redes, segurança e programação) em ferramentas simples, documentadas e que rodam de verdade.

## Projetos

| Projeto | O que faz | Status |
|---|---|---|
| Validador de senhas | Verifica se uma senha é forte (tamanho, tipos de caracteres, padrões fracos) | Em desenvolvimento |
| Port scanner | Testa quais portas TCP estão abertas em um host, usando sockets | Planejado |
| Analisador de logs | Lê arquivos de log e destaca tentativas de acesso suspeitas | Planejado |

## Como rodar

Cada projeto terá sua própria pasta com um README, exemplos de uso e instruções. Requisito: Python 3.10 ou superior.

## Aviso

Os projetos são feitos para estudo e uso defensivo. Só teste ferramentas em sistemas seus ou com autorização.
